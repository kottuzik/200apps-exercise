# 200apps-exercise / Vue Dashboard Template

## Technologies Used

- **Vue 3** — JavaScript framework for building user interfaces
- **PrimeVue** — UI component library for Vue
- **PrimeIcons** — Icon library for PrimeVue
- **Pinia** — State management for Vue
- **Chart.js** & **chartjs-plugin-datalabels** — For charts and data visualization
- **SCSS (Sass)** — CSS preprocessor for advanced styling
- **Tailwind CSS** — Utility-first CSS framework
- **Vite** — Fast frontend build tool
- **PostCSS** & **Autoprefixer** — CSS processing and vendor prefixing

## Installation

1. **Go to the project directory:**
   ```bash
   cd 200apps-exercise/vue-dashboard-template
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser and go to:**
   ```
   http://localhost:5173
   ```
